# একদিন ফিরব

শূন্য থেকে পাঁচ কোটি মানুষ পর্যন্ত — একটা ছোট সিদ্ধান্তের গেম।

**খেলুন:** https://onelpawarai-x.github.io/zyraxon-studio/ekdin-firbo/

ছয় বছর, ছয়টা ধাপ। প্রতিটা ধাপে দুই-তিনটা পথ। শেষে চারটা জিনিস গণনা হয় —
টাকা, টিম, মানুষ, আর বিশ্বাস। বিশ্বাসটাই সবচেয়ে ভারী।

> "একদিন এমনভাবে হারিয়ে যাব, কেউ খুঁজে পাবে না।
> আবার এমনভাবে ফিরব, কেউ ভুলতে পারবে না।"
